EXECUTIVE MONOGRAPH ABSTRACT

Decentralized Agent Swarms vs. Centralized Orchestrators

Authored by Dr. Arvind Swaminathan and Fellowship Cohort 03 Fellows. Published August 2026.

Key Findings & Empirical Data:
• Single-Point Failures: Centralized router architectures collapsed when tool invocation error rates crossed 4.2%
• Gossip Protocols: Peer-to-peer state distribution reduced mean-time-to-recovery (MTTR) by 76% under node preemption
• Token Overhead: Hierarchical supervisor trees consumed 38% fewer tokens than fully meshed agent networks
• Code Release: Benchmarks released under MIT license on the Bloombridge Research GitHub

BENCHMARK SUMMARY

KV-Cache Compression in Production LLM Serving

Authored by Bloombridge Systems Lab. Evaluated on 8x NVIDIA H100 SXM5 with vLLM v0.6+ and FlashInfer.

Key Optimization Metrics:
• VRAM Reduction: FP8 dynamic quantization lowered per-token cache storage from 32 bytes down to 8.2 bytes
• Throughput Multiplier: Concurrent request capacity doubled from 180 req/s to 410 req/s per server node
• Perplexity Delta: Zero measurable loss on MMLU and GSM8K benchmarks with context lengths up to 64k tokens
