A production-grade demonstration website representing ScaleNova's **EliteOS Tier** for higher education institutes, executive upskilling academies, and professional training academies.

## Features
- **Modern Academic Design System**: Royal Violet (`#120A2B`), Wisteria Lavender (`#F5F3FF`), and Rose accents (`#EC4899`).
- **Interactive Competency Constellation Canvas**: Multi-dimensional dynamic skills radar with interactive node physics.
- **12 Rich Content & Operational Pages**:
  - `index.html` (Hero, competency canvas, academy stats, core tracks)
  - `about.html` (Pedagogical methodology, faculty council, accreditation)
  - `programs.html` (Complete curriculum tracks in AI, FinTech, CTO Leadership)
  - `program-detail.html` (Deep dive into Applied Generative AI & Enterprise Architecture)
  - `career-development.html` (1-on-1 executive coaching & 140+ hiring network)
  - `learning-experience.html` (Hybrid studio model & dedicated GPU quotas)
  - `success-stories.html` (Alumni career pivots and venture funding)
  - `admissions.html` (3-stage selection process and fellowship criteria)
  - `book-counselling.html` (Full candidate application & evaluation booking form)
  - `insights.html` (Frontier engineering whitepapers & salary reports)
  - `contact.html` (Campuses in Bengaluru, Gurugram, and Singapore)
  - `privacy.html` (Student record privacy & DPDP data policy)
- **Shared Integration Gateway**: Routes directly to Google Apps Script `DEMO-04`, updating Google Sheet `Demo4_Education` and Frappe CRM (`demo.scalenovasys.com`).

## Quick Start
```bash
npm install # optional
npm run dev # runs serve at port 3004
npm test    # runs system validation test
```
